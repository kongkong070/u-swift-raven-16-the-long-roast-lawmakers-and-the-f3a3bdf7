One satirical sentence, written by a small Node program (`main.ts`) that
writes it to `/output/entry.txt`.

> They will write nine hundred pages of law to govern artificial intelligence, cryptocurrency, and the entire internet, yet hand one of them a Word document and ask for a PDF, and the fate of the free world suddenly rests on an intern who knows where 'Save As' lives.

Run: `node --experimental-strip-types main.ts` (or `node main.ts` on Node 22+ with type stripping) with `MAKEFUN_OUTPUT_DIR` set to the output directory.
